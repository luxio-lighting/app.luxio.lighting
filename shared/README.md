# Vendored Luxio sources

Protocol definitions and the browser-compatible Lua runtime are snapshots from `next/luxio-ios/shared/`, copied on 2026-10-26. Keep this app independently buildable; update snapshots deliberately rather than importing neighboring repositories.

`web/vendor/fengari.mjs` is generated from the installed Fengari package by `tools/build-browser.mjs` and is not source-controlled.
